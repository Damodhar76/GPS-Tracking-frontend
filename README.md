# Lambodra GPS Tracking Experience

Premium Next.js GPS and fleet-tracking experience with:

- React Three Fiber spatial globe
- Local GLB hardware model with exploded layers
- Scroll-driven 3D vehicle journey
- Route replay and speed controls
- Interactive geofence polygon builder
- Live alert and sound simulator
- OBD-II vehicle diagnostics
- Advanced Tailwind CSS responsive interface

See `VERCEL_DEPLOYMENT.md` for drag-and-drop deployment instructions.
